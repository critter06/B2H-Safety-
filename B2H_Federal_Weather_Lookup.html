B2H FEDERAL LAND WEATHER LOOKUP

BLM & USFS structures · 311 records · QISG · Project 032
This tool cannot pull historical weather values directly (Weather Underground's archive requires interactive navigation, and NOAA's historical API requires an account token). Instead, it identifies the nearest reporting station to your structure and builds a direct link to that exact date so you can read the value in one click.

Station distances from structures vary (5–30 miles) — treat readings as regional context, not site-specific measurement, especially for wind.
